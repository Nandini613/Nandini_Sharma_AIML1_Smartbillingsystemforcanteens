# Nandini_Sharma_AIML1_Smartbillingsystemforcanteens
 PROJECT TITLE - Smart Billing System for Canteens
 PROJECT DESCRIPTION- It enables users to browse a digital menu, place orders. Admins can monitor sales, manage menu items, and view analytics through a centralized dashboard. This project aims to enhance efficiency, reduce waiting times, and improve the overall user experience in canteen operations.
